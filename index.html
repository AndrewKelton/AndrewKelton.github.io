A Parallel TF-IDF Implementation in C++

Completed

A multithreaded TF-IDF vectorizer and text classifier written in C++. It computes TF-IDF scores across a training corpus, sorts documents into categories, then classifies unseen documents using cosine similarity (0.8 trained : 0.2 un-trained ratio). The first multithreaded TF-IDF implementation for efficient text classification in C++.
